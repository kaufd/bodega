# Погребокъ — дневник алкогольных напитков · спецификация для реализации

> Личное приложение для одного пользователя. **Без регистрации, авторизации, бэкенда, синхронизации и социальных функций.** Всё хранится локально на устройстве.
> Источник дизайна — файл `Погреб - стартовый экран.dc.html` (это макет-спецификация, **не код для переноса**: берите из него значения и структуру, транслируйте в нативный UI).

## 1. Стек
- **Android, нативно: Kotlin + Jetpack Compose.**
- Локальные данные: **Room** (сущности записей), **DataStore** (настройки/последний выбранный фильтр).
- Фото: системный photo picker / камера, файлы во внутреннем хранилище, кэш миниатюр.
- Минимум сторонних зависимостей.

## 2. Модель данных

Одна таблица записей с общими полями + поля, зависящие от категории.

### Общие поля (все категории)
| Поле | Тип | Обязательное | Примечание |
|---|---|---|---|
| id | Long (PK) | да | автоинкремент |
| category | enum: `WINE` / `BEER` / `SPIRIT` | да | категория |
| name | String | да | название |
| photoPath | String? | нет | путь к файлу фото |
| type | String? | нет | тип (см. ниже) |
| priceRub | Int? | нет | цена покупки, ₽ |
| rating | Int? (1–10) | нет | **целое, шкала 1–10** |
| abvPercent | Double? | нет | крепость, % |
| volumeMl | Int? | нет | объём (0,33 л = 330 и т.п.) |
| note | String? | нет | текстовая заметка |
| tastedAt | Date? | нет | дата дегустации |
| createdAt | Date | да | служебное |

### Поля по категориям
- **WINE (вино):** `grape` (сорт, напр. «Неббиоло»), `country` (страна/регион — **только у вина**), `vintageYear` (год).
- **BEER (пиво):** `style` (стиль, напр. «Квадрюпель»). Страны и года нет.
- **SPIRIT (крепкое):** `ageStatement` (выдержка, напр. «16 лет»). Страны нет.

> `type` для вина = «Красное, сухое»; для пива = «Тёмный эль»; для крепкого = «Виски (скотч)».

## 3. Экраны и переходы

### 3.1 Главная — вариант **6a** (выбран)
- Заголовок по центру: **Погребокъ** + подзаголовок «журналъ дегустацій».
- Строка поиска (белое поле «искать в журнале…») + отдельная тёмная кнопка фильтров справа с бейджем количества активных фильтров.
- Строка-разделитель: «Все категории · N» слева, индикатор сортировки «баллъ ↓» справа.
- Список записей (ledger-стиль): миниатюра 46×46, название (Cormorant), «тип · страна/происхождение» (мелким), справа — **балл** (цветом категории) и цена (моно).
- **Нижний таб-бар = категории:** `Все · Вино · [+] · Пиво · Крепкое`.
  - Иконки: Все — сетка 2×2; Вино — бокал; Пиво — кружка; Крепкое — стакан (в цветах категорий).
  - По центру — **приподнятая круглая кнопка «+»** (добавление записи).
  - Активный таб выделен (у «Все» — залитая «пилюля» под иконкой).
- Тап по строке → карточка записи. Тап по «+» → создание.

### 3.2 Карточка записи
- Верхняя панель: назад (←), справа «⋯».
- Фото (уменьшенное, ~200 dp, скруглённое, с меткой категории и, если избранное — можно опустить).
- Название (крупно) + подзаголовок «сорт · тип · страна».
- Блок оценки: крупное число `9` + `/10` и шкала из 10 делений (залито = баллу), подпись «Моя оценка».
- Характеристики (список пар ключ–значение с разделителями): Сорт, Тип, Страна (только вино), Год/Выдержка, Крепость, Цена покупки, Дата дегустации.
- Заметка (курсив).
- **Действие «Редактировать» — в шапке** (выбранный вариант: «Править» в правом верхнем углу; без нижней панели).

### 3.3 Создание / редактирование
- Верхняя панель: «Отмена» слева, «Сохранить» справа (цветом категории).
- Загрузка фото (пунктирная зона «Добавить фото»).
- Переключатель категории (сегменты Вино/Пиво/Крепкое) — **набор полей меняется по категории:**
  - Вино: Сорт, Тип, **Страна**, Год, Крепость, Объём, Цена.
  - Пиво: Стиль, Тип, Крепость, Объём, Цена (без страны/года).
  - Крепкое: Тип, **Выдержка**, Крепость, Объём, Цена (без страны).
- Оценка 1–10 — ряд из 10 кнопок, выбранная залита цветом категории.
- Заметка — многострочное поле.

### 3.4 Поиск и фильтры
Фильтры открываются кнопкой рядом с поиском, **полноэкранно** (не bottom sheet — чтобы не было тесного скролла):
- Категория: Все / Вино / Пиво / Крепкое.
- Стиль и тип — сгруппировано по категориям (Красное/Белое/Игристое; IPA/Портер/Стаут; Виски/Ром/Текила…).
- Оценка — двойной ползунок по шкале **1–10**.
- Цена покупки — диапазон.
- Страна — чипы (актуально для вина).
- Сортировка — По баллам / По цене / По дате.
- Внизу — кнопка «Показать N записей».

### 3.5 Состояния (реализовать)
Три пустых состояния (макеты 8a/8b/8c), все в стиле главной 6a (шапка, таб-бар, центральная «+»): по центру — иконка в круге Ø92, заголовок (Cormorant ~26), пояснение (14.5, приглушённое), кнопка.

- **8a · Пустая коллекция** (записей вообще нет). Иконка — сетка 2×2 (приглушённая) в круге `#FBF6EC`. Заголовок «Погреб пока пуст». Текст «Заведите первую запись — вино, пиво или крепкое, — и она появится в вашем журнале дегустаций.» Кнопка (залитая `#2E2620`) «+ Добавить первую запись».
- **8b · Пустая категория** (напр. «Вино» пусто). Иконка бокала в круге с тинтом категории (`#EBD9D3`), сам бокал — цветом категории. Заголовок «В разделе «Вино» пусто». Текст «Здесь появятся ваши вина. Добавьте первую бутылку, чтобы начать вести раздел.» Кнопка залита **цветом категории** «+ Добавить вино». (Аналогично для пива/крепкого с их цветами и текстами.)
- **8c · Пустой результат поиска/фильтра**. Сверху сохраняется строка поиска с введённым запросом (крестик очистки) и кнопкой фильтров. Иконка — лупа (приглушённая) в круге. Заголовок «Ничего не найдено». Текст «По запросу «…» с текущими фильтрами записей нет. Попробуйте изменить запрос или сбросить фильтры.» Кнопка **контурная** «Сбросить фильтры».

- **Удаление записи** — диалог подтверждения + возможность отмены (undo, напр. Snackbar).

## 4. Дизайн-токены

### Цвета
- Фон-«бумага» экрана: `#F4ECDB`; фон-полотно списка/сцены: `#F2E9D8`.
- Поверхности/карточки: `#FBF6EC`; поля ввода: `#FFFFFF`.
- Текст (чернила): `#2E2620`; приглушённый: `#6B5D4E`, `#5E5140`; плейсхолдеры/подписи: `#9A8B78`, `#8A7A66`.
- Разделители (hairline): `rgba(46,38,32,0.10)`.
- **Акценты категорий** (в макете заданы в oklch; ниже приближённые hex):
  - Вино: `oklch(0.48 0.11 25)` ≈ `#9B3A34` (бордо).
  - Пиво: `oklch(0.60 0.11 78)` ≈ `#B0842E` (янтарь).
  - Крепкое: `oklch(0.50 0.09 55)` ≈ `#8A6440` (медь).
- Тинты плейсхолдеров фото: вино `#EBD9D3`, пиво `#EFE3C9`, крепкое `#E6DBCB`.

### Шрифты
- **Rubik** — всё, кроме чисел: заголовки, названия напитков, вордмарк, основной текст, подписи кнопок.
- **IBM Plex Mono** — числа: баллы, цены, крепость, объём, а также мелкие подписи-лейблы (CAPS, letter-spacing).

Изначально спека называла Cormorant Garamond для заголовков и Spectral для текста;
в приложении обе заменены на Rubik (в `res/font/` лежат только `rubik_variable` и
`ibm_plex_mono`). Ниже по документу упоминания Cormorant читать как Rubik.

### Прочее
- Баллы — **целые 1–10** (не 1–100, без дробей).
- Радиусы: поля/карточки 10–16; чипы/пилюли — полностью скруглённые.
- Минимальные тач-таргеты ≥ 44 dp.
- Эмодзи не использовать. Иконки — простые контурные (бокал/кружка/стакан, лупа, ползунки-фильтр, карандаш, «назад»).
